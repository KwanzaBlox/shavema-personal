# Шаверма персонал

Приложение для учёта смен, кассы, зарплат и премий трёх поваров заведения быстрого питания.

## Возможности (что уже работает)

- **Обзор** — моя зарплата, часы, общая касса, выполнение плана, ближайшая смена.
- **Календарь** — график по месяцам, смены, статусы дней (рабочий / выходной / отпуск / больничный).
- **Зарплата** — разбивка по дням, фильтр по сотруднику и месяцу, итоги.
- **Касса и план** — одна сумма кассы на день, месячный план, процент выполнения, динамика, предупреждение об отставании.
- **Отчёты** — месячная статистика и экспорт в Excel (3 листа: график, касса, зарплата).
- **Настройки** — базовая ставка, множитель одиночной смены, порог длительной смены, таблица премий.

Правила расчёта:
- Базовая ставка — **170 ₽/час**.
- Основной повар, работавший один, получает **255 ₽/час** (×1.5) — только за часы, не за премию.
- Премия за дневную кассу считается по **одной дневной сумме** и делится между поварами пропорционально ролям (основной = 1, дополнительный = 0.5; дополнительный получает 1, если отработал порог длительной смены — по умолчанию 12 ч).

## Запуск на компьютере

Нужен Node.js LTS и npm. В терминале VS Code (в папке проекта):

```bash
npm install     # один раз, если node_modules ещё нет
npm run dev     # запустить в режиме разработки
```

Открой `http://localhost:5173/`.

## Сборка и проверки

```bash
npm run build               # собрать готовую версию в папку dist
node tests/calc.test.ts     # запустить тесты расчётов
```

## База данных Supabase (онлайн-синхронизация)

1. Создай бесплатный проект на https://supabase.com.
2. В разделе **SQL Editor** выполни целиком файл `supabase/schema.sql`.
3. Скопируй `.env.example` в файл `.env.local` и заполни своими ключами
   (Project Settings → API): `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
4. После регистрации Дмитрия сделай его администратором:
   `update public.profiles set role = 'admin' where full_name = 'Дмитрий';`

⚠️ В клиентский код можно вставлять только **anon key**. Секретный ключ
`service_role` не должен попадать в код или в Git.

## Размещение на Vercel (бесплатно)

Чтобы приложение было доступно с телефонов, размести его на Vercel:

1. Установи Git — https://git-scm.com/download/win (жми «Далее» везде).
2. Создай бесплатный аккаунт на https://github.com и репозиторий `shaverma-personal`.
3. Залей проект (в терминале VS Code, в папке проекта):
   ```bash
   git init
   git add .
   git commit -m "Первая версия"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/shaverma-personal.git
   git push -u origin main
   ```
4. Зайди на https://vercel.com → войди через GitHub → **Add New Project** →
   выбери репозиторий `shaverma-personal` → Deploy.
5. В Vercel: проект → **Settings → Environment Variables** → добавь ДВА значения
   (скопируй их из файла `.env.local`):
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
6. Пересобери проект (Vercel → Deployments → ⋯ → Redeploy), чтобы ключи применились.
7. Готовый адрес вида `https://....vercel.app` открой на телефоне и добавь
   на главный экран (PWA — манифест и иконки уже подключены).

## Сборка Android APK

Проект уже подготовлен (Capacitor + папка `android/`). Для сборки APK:

1. Установи Android Studio — https://developer.android.com/studio
2. Открой в Android Studio папку `android/` проекта (File → Open → выбрать папку android).
3. Дождись первой синхронизации Gradle (скачает зависимости — займёт время).
4. Перед сборкой обнови веб-часть:
   ```bash
   npm run build
   npx cap sync android
   ```
5. В Android Studio: меню **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
6. Готовый файл появится в `android/app/build/outputs/apk/debug/app-debug.apk`.
   Его можно перекинуть на телефон и установить.
